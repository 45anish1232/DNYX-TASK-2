# 🌦 Weather App

A simple and responsive **Weather Application** built using **HTML, JavaScript, and Tailwind CSS**.  
The app fetches real-time weather data from the **OpenWeatherMap API** and displays current weather details along with a 5-day forecast.

---

## 🚀 Features

- 🌍 Search weather by city name
- 🌡 Displays current temperature, humidity, wind speed, and weather condition
- 🔁 Toggle between **Celsius (°C)** and **Fahrenheit (°F)**
- 📅 5-Day weather forecast
- 🎨 Modern UI built with **Tailwind CSS**
- ⚡ Real-time data fetched using **Fetch API**

---

## 🛠 Tech Stack

- **HTML5** – Structure  
- **Tailwind CSS** – Styling & responsive design  
- **JavaScript (ES6)** – Logic & API handling  
- **OpenWeatherMap API** – Weather data source
